# Modern Laravel & Tailwind Hero Component

Laravel Blade ve Tailwind CSS kullanılarak geliştirilmiş, SEO ve Core Web Vitals uyumlu hafif (lightweight) açılış sayfası hero bileşeni.

## 🚀 Özellikler
- **Framework:** Laravel 10 / 11 Blade Engine
- **CSS:** Tailwind CSS v3+
- **Uyumluluk:** Tam responsive ve koyu tema (dark mode) odaklı
- **Performans:** Sıfır JS bağımlılığı, temiz DOM mimarisi
